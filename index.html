About this demo store

Mini Shop QA is a small static storefront built to exercise every part of an Optimizely Web experiment: pages with near-identical URLs, repeated list items, hand-written class hashes, late-rendering widgets and responsive layouts.

Nothing here is real. Carts live in your browser's localStorage, checkout never leaves the page, and the only network traffic is the Optimizely snippet.

Scroll further and you will find the newsletter form and a debug line showing which visitor attributes the page pushed to Optimizely before the snippet loaded.

Every product page has accordions, colour swatches, a desktop-only size guide and a mobile-only sticky add-to-cart bar, so changes can be checked across viewports.
